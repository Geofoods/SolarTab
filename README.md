## Features

-  **NASA APOD wallpaper** - today's picture of the day as the background image
-  **Live clock** - live clock that you can customize from 12-hour to 24-hour time with the added ability to change timezones as well
-  **Web search bar** - browse the web
-  **Customizable quick links** - add, remove, and edit bookmarks
-  **Descriptions** - Get descriptions of what the photos mean and be able to go through past photos
-  **Settings Menu** - Change from light/dark mode and change accent color
-  **Search Engine Choose** - Browse the web using your preferred search engine or use your own one as well
-  **Widgets** - ISS locator, moon phase, space news, calendar, todo list, weather, and recent searches
